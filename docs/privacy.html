content-agent 개인정보처리방침

시행일: 2026-11-09

content-agent는 운영자가 자신이 관리하는 YouTube 채널(LinkAnswer Power, LinkAnswer Wealth)에 영상을 예약 업로드하고, 그 채널의 공개 성과(조회수 등)를 확인하고, 자신의 영상에 댓글을 다는 데만 쓰는 내부 운영 도구입니다. 일반 사용자를 대상으로 하는 서비스가 아닙니다.

1. 사용하는 정보

  • 운영자 본인 Google 계정의 YouTube 권한(업로드, 읽기, 분석 읽기, 댓글)만 사용합니다.
  • 다른 사람의 개인정보는 수집하지 않습니다.

2. 이용 목적

운영자 채널의 영상 예약 업로드, 채널·영상 성과 확인, 운영자 영상의 댓글 게시에만 사용합니다. 광고, 판매, 제3자 제공에 쓰지 않습니다.

3. 보관과 보호

로그인 토큰은 운영자의 컴퓨터에만 저장되며 외부로 보내지 않습니다. 운영자는 언제든 Google 계정 권한 페이지에서 접근을 취소할 수 있습니다.

4. Google API 사용

content-agent가 Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

content-agent Privacy Policy

content-agent is an internal tool used only by its operator to schedule uploads to, read analytics for, and post comments on the operator's own YouTube channels. It is not offered to the public. It uses only the operator's own Google account authorization and does not collect anyone else's personal data. Tokens are stored only on the operator's computer and are never shared or sold. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
